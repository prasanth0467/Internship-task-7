# Sales Summary Task

Data analysis practice task where MySQL and Python is used to generate a basic sales summary.

## Task Objectives

- Connect Python to a MySQL database using PyMySQL
- Query total quantity sold and total revenue per market using SQL
- Load data into a Pandas DataFrame
- Visualize revenue by product using a bar chart (matplotlib)

## Files Included

- `notebook task 7-checkpoint.ipynb`: Jupyter notebook with all the code and output
- `Sales_chart.png`: Bar chart showing revenue by market

## Tools Used

- Python
- MySQL
- PyMySQL
- Pandas
- Matplotlib
